# BRICKS: Buffered RoPE-offset Independent Composed KV System for Zero-Recompute RAG Inference

Long-context Large Language Models (\textbf{LLMs}) face severe prefill latency bottlenecks, commonly measured as Time-to-First-Token (\textbf{TTFT}), in high-concurrency Retrieval-Augmented Generation (\textbf{RAG}) scenarios. While fully reusing the key-value (\textbf{KV}) cache of retrieved documents theoretically eliminates this bottleneck, naive reuse introduces severe cross-document attention disruption and context fragmentation, causing catastrophic drops in generation quality. Recent partial-recompute methods, such as \textbf{CacheBlend}, attempt to restore quality via selective recalculation. However, they still incur non-trivial computational overhead and rely heavily on underlying hardware \textbf{I/O} pipelining to hide latency, which fundamentally limits their scalability under peak industrial throughput.

To break this compute-memory trade-off, we propose \textbf{BRICKS} (\textbf{B}uffered \textbf{R}oPE-offset \textbf{I}ndependent \textbf{C}omposed \textbf{K}V \textbf{S}ystem), a purely \textbf{Z}ero-\textbf{R}ecompute \textbf{KV} cache assembling framework. By introducing three orthogonal components, specifically Shared Header Injection to act as a shared attention anchor, Separator Appending to serve as inter-document buffer tokens, and native \textbf{RoPE} Offset Repair, \textbf{BRICKS} mathematically reconstructs a healthy attention matrix entirely at the physical memory level and circumvents the need for any online forward passes. Extensive evaluations on \textbf{Llama-3.1-8B} reveal that \textbf{BRICKS} operates with an \textit{$O(1)$} tensor concatenation time, delivering an average \textbf{TTFT} speedup of over $10\times$ compared to full recomputation. Furthermore, it successfully retains 93.19\% of the generation quality of full recomputation on challenging multi-document datasets such as \textbf{2WikiMQA}, providing a novel perspective for \textbf{KV} reuse in \textbf{RAG}.
